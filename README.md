# Stream TTS Studio

**Локальная TTS-студия для стриминга на базе CosyVoice 3.** Генерирует речь из текста, поддерживает несколько голосовых персонажей и связывает озвучку с OBS, Streamer.bot и DonationAlerts.

Проект рассчитан на локальную Windows-машину с NVIDIA GPU. Генерация выполняется локально.

[Подробная документация: установка, настройка, эксплуатация, API и архитектура](docs/README.md).

## Быстрый запуск

1. Скачайте и распакуйте архив в удобное место. Рекомендуется путь без кириллицы, пробелов и специальных символов, например **C:\StreamTTS**.
2. Запустите **start_studio.bat**.
3. Дождитесь запуска backend и открытия Monitor. Dashboard можно открыть из меню значка приложения в системном трее.
4. Создайте или выберите голосового персонажа, загрузите голосовой референс и проверьте генерацию.

Установка Python и ML-зависимостей вручную не требуется: portable runtime поставляется отдельно от Git-репозитория и должен находиться рядом с файлами приложения в каталоге **cosyvoice3**.

**Альтернативный запуск:** start_server.bat запускает backend напрямую в консоли, без Launcher и системного трея. Не запускайте оба режима одновременно.

Закрытие окна Monitor не завершает Studio — приложение продолжает работать в фоне. Для полного завершения используйте пункт **«Выход»** в меню значка трея.

Подробности и диагностика: [Запуск и эксплуатация](docs/OPERATIONS.md).

## Требования к компьютеру

- Windows 10/11 x64.
- NVIDIA GPU с поддержкой CUDA.
- Драйвер NVIDIA, совместимый с используемой CUDA-сборкой PyTorch.
- Достаточно свободной видеопамяти для TTS и одновременно запущенных приложений.

В проверенной конфигурации используется **PyTorch 2.7.1 + CUDA 12.8**. Сборка ориентирована на RTX 20/30/40/50; непосредственно проверенная видеокарта владельца — **RTX 5080**. Совместимость остальных моделей не означает, что каждая из них отдельно протестирована.

### Видеопамять

В рабочем сценарии владельца Studio занимает ориентировочно **4–5 ГБ VRAM**. Фактическое потребление зависит от модели, текста и нагрузки системы.

### Использование во время игр

Studio может работать в фоне параллельно с играми. На RTX 5080 владелец использовал её вместе с требовательными играми, в том числе на высоких и Ultra-настройках.

Если игра почти полностью занимает VRAM или GPU (например, с тяжёлым Ray Tracing / Path Tracing), свободных ресурсов для генерации может не хватить. Для стабильной работы оставляйте запас видеопамяти.

## Возможности

- Локальная генерация речи через CosyVoice 3 и voice cloning по референсу.
- Несколько голосовых персонажей с отдельными голосами, настройками и аватарами.
- Редактор референса: загрузка, обрезка, нормализация, транскрипция и тестовая генерация.
- Автоматическая транскрипция через faster-whisper.
- Разбиение длинного текста на фрагменты и сборка результата в единый WAV.
- Настройка скорости речи и экспорт аудио.
- Подготовка аудио через FFmpeg, включая конвертацию в OGG/Opus для Telegram.
- OBS Browser Source Overlay с аватарами, темами, шрифтами и анимацией.
- Интеграция со Streamer.bot: TTS, Follow, Raid и DonationAlerts Actions.
- Генератор готового C#-кода для Streamer.bot.
- Локальный HTTP API и WebSocket для интеграций.

## Первоначальная настройка

### OBS

1. Откройте Dashboard и перейдите к настройкам Overlay.
2. Скопируйте URL Browser Source.
3. В OBS добавьте источник **Browser** и вставьте URL.
4. Настройте размер, положение и оформление Overlay в Dashboard.

### Streamer.bot

1. Убедитесь, что Streamer.bot запущен и доступен по настроенному HTTP API.
2. В Dashboard откройте генератор Actions.
3. Выберите тип события и настройте параметры.
4. Сгенерируйте C#-код и вставьте его в соответствующий Action Streamer.bot.
5. Проверьте Action тестовым событием.

Поддерживаются шаблоны **tts**, **follow**, **raid** и **donate**. Владелец проверил рабочие варианты всех четырёх шаблонов непосредственно в Streamer.bot.

### DonationAlerts

1. Создайте OAuth-приложение DonationAlerts и укажите callback: **http://127.0.0.1:8765/api/da/callback**.
2. Введите Client ID и Client Secret в настройках интеграции Dashboard.
3. Пройдите OAuth-подключение.
4. Укажите адрес Streamer.bot и имя Action, который должен запускаться при донате.
5. Выполните тестовый донат из Dashboard.

## Основа проекта и благодарности

Studio создана на основе portable-сборки CosyVoice 3 [mortimerme/repocollect — cosyvoice3-0529.7z](https://huggingface.co/mortimerme/repocollect). Вокруг исходной сборки разработаны интерфейс, аудиообработка, API, OBS Overlay и интеграции для стриминга.

Используются [CosyVoice 3](https://github.com/FunAudioLLM/CosyVoice), [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper), [FFmpeg](https://ffmpeg.org/) и [ONNX Runtime](https://onnxruntime.ai/). Благодарность авторам этих проектов и авторам исходной portable-сборки.

Инструменты синтеза и клонирования голоса предназначены для законного создания контента с согласия правообладателей и людей, чей голос используется. Не применяйте их для мошенничества, обмана, выдачи себя за другого человека или иных незаконных действий.
