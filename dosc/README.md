## Статус документации

Документы описывают наблюдаемое поведение кода. Сведения из README проекта отмечаются как заявленные проектом; они не считаются независимо проверенными тестами. В текущем репозитории не обнаружены автоматические тесты, CI-конфигурация или манифест Python-зависимостей. Поэтому это статический аудит, а не подтверждение успешной сборки/запуска на целевой машине.

## Область аудита

Проверены дерево репозитория, README, backend `server/app.py`, frontend Dashboard (`web/dashboard/*`), OBS Overlay (`web/overlay/*`) и стартовый BAT-файл.
