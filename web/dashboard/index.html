5. Базовые примеры интеграции (API)

Эндпоинт POST /speak принимает JSON. Параметры character (ID) и speed (скорость) опциональны — если их не передавать, используется активный по умолчанию персонаж.
cURL (Консоль / Запрос) 
# Озвучка активным персонажем:
curl -X POST "http://127.0.0.1:8765/speak" \
     -H "Content-Type: application/json" \
     -d "{\"text\": \"Привет, мир!\"}" \
     --output speech.wav

# Озвучка с явным указанием персонажа и скорости:
curl -X POST "http://127.0.0.1:8765/speak" \
     -H "Content-Type: application/json" \
     -d "{\"text\": \"Привет!\", \"character\": \"mita\", \"speed\": 1.1}" \
     --output speech.wav
Python 
import requests

url = "http://127.0.0.1:8765/speak"
payload = {
    "text": "Привет от нейросети!",
    "character": "mita",  # Необязательно (по умолчанию активный)
    "speed": 1.0          # Необязательно (от 0.5 до 1.5)
}

response = requests.post(url, json=payload)
if response.status_code == 200:
    with open("output.wav", "wb") as f:
        f.write(response.content)
    print("Звук сохранен в output.wav")
