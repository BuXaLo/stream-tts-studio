## Важное уточнение о поставке и проверке

Актуальная рабочая ветка изменений — `dev_test`; `dev` и `main` не изменялись. Статусы и инструкции в этом комплекте документации относятся к `dev_test`.
Git-репозиторий содержит код приложения. Portable-окружение, Python, ядро CosyVoice, ML-модули, модели и прочие инструменты поставляются отдельно большим архивом; поверх этой основы устанавливается код Stream TTS Studio. Окружение изолировано и рассчитано на локальный Windows-ПК.

Владелец проекта сообщил, что приложение уже проверено многими часами реальных стримов: генерация аудио работает, а связка OBS и Streamer.bot используется в рабочем процессе. Это важное эксплуатационное свидетельство владельца, но не результат независимого запуска текущей копии репозитория аудитором.

## Принцип дальнейшей разработки
**Не ломать работающий эфирный тракт.** Сохранить portable runtime и его версии, команды запуска, существующие API/payloads, пути и форматы пользовательских данных, поведение OBS Overlay, C# Actions Streamer.bot и сценарии генерации. Улучшения выполнять малыми изолированными изменениями, сначала покрывая существующее поведение тестами/контрольными сценариями, затем меняя реализацию и повторяя проверки.

Никакая задача из ROADMAP не является разрешением на массовый рефакторинг или миграцию runtime. Изменение публичного контракта или формата данных требует отдельного обоснования, миграции, плана отката и явного согласования.

## Как читать результаты аудита
Различайте:
- **подтверждённое наблюдением кода** — например, конкретный способ вставки текста в DOM;
- **эксплуатационный факт со слов владельца** — длительная работа генерации и интеграций в реальной среде;
- **потенциальный риск** — зависит от конфигурации, доступности интерфейса и модели угроз;
- **непроверенное** — portable archive, runtime-зависимости и поведение на конкретной машине.

Аудит исходников сам по себе не доказывает нестабильность приложения. Backend уже разделён на `studio/core`, `studio/services` и `studio/routes`; `server/app.py` — компактный bootstrap/entrypoint (около 278 строк с учётом пустых строк и комментариев). В репозитории настроен GitHub Actions CI: compileall, pytest и JavaScript syntax checks. Синхронный I/O следует оценивать по конкретным измерениям, а не считать дефектом сам по себе.
