# Portable runtime — baseline и inventory

> Снимок локальной рабочей установки владельца проекта от 2026-11-15. Это фактическая конфигурация одной Windows-машины, а не универсальные требования для всех систем и не гарантия чистого состояния GitHub-архива.

## Размещение

Код Stream TTS Studio загружается архивом GitHub и распаковывается непосредственно в корень установки. Portable runtime расположен рядом с кодом в каталоге `cosyvoice3\` и не отслеживается Git как часть исходников приложения.

В проверенной установке:
- корень Studio: `D:\TTS_release\`;
- portable runtime: `D:\TTS_release\cosyvoice3\`;
- portable Python: `cosyvoice3\upy\python.exe`;
- локальный FFmpeg: `cosyvoice3\tools\ffmpeg.exe`.

Владелец может вручную проводить тесты и менять файлы после распаковки архива. Поэтому этот снимок описывает реально используемую установку на дату проверки; он не привязан к Git commit и не утверждает, что все файлы совпадают с исходным архивом.

- Снимок не включает Git commit, SHA-256 файлов, контрольную сумму архива или полный перечень всех файлов runtime.
- Размеры и версии относятся к состоянию на 2026-11-15 и должны обновляться при намеренном изменении portable runtime.
- Этот документ не является разрешением обновлять Python, CUDA, PyTorch, CosyVoice, модели или другие runtime-компоненты. Их изменение требует отдельного решения и проверки совместимости.


## Лицензии portable runtime — статус inventory

Снимок версий и размеров выше не является лицензионным inventory: он не содержит полного списка Python-пакетов, их зависимостей, файлов LICENSE/NOTICE, точных ревизий исходных проектов и конфигурации сборки бинарников. Portable runtime находится вне Git, поэтому лицензии нельзя исчерпывающе подтвердить только по этому репозиторию.

На дату снимка известны следующие компоненты и исходные ориентиры:

- CosyVoice — официальный upstream QwenAudio/FunAudioLLM публикует код под Apache License 2.0. При распространении производных/вендоренных файлов нужно сохранить LICENSE, применимые NOTICE/атрибуции и уведомлять об изменённых файлах. Состав каталога `third_party` и точная ревизия кода в локальном архиве ещё не сверены.
- `Fun-CosyVoice3-0.5B-2512` — официальный model card указывает Apache-2.0. Локальный каталог называется `Fun-CosyVoice3-0.5B`; проверка SHA-256 `llm.pt` ранее совпала с официальным файлом, но это не закрепляет immutable revision для всех остальных файлов модели и вспомогательных ресурсов.
- PyTorch 2.7.1 — метаданные PyPI указывают BSD-3-Clause; wheel также содержит лицензии ряда сторонних компонентов. Нельзя ограничиваться одной строкой BSD: при распространении нужно сохранить лицензионные файлы wheel и проверить включённые бинарные зависимости.
- FFmpeg 7.1.1 из Gyan Full Build — GPLv3. Архив и локальный EXE идентифицированы по SHA-256; Gyan предоставил manifest зависимостей/инструментов сборки с upstream URL и commit hash и подтвердил отсутствие функциональных патчей. Manifest и пояснения сохранены в [лицензионных материалах FFmpeg](../licenses/ffmpeg/BUILD_INFO.md). Это улучшает трассируемость исходников, но независимое получение всех pinned source revisions/packages и проверка полноты build-toolchain материалов ещё не выполнены. В репозитории сохранён полный текст GPLv3 в `licenses/ffmpeg/COPYING.GPLv3`; в portable runtime также имеется `tools/LICENSE.GPL.txt`. При сборке portable-поставки необходимо сохранить лицензионный текст рядом с FFmpeg и предоставить пользователям доступ к соответствующим исходникам и материалам сборки.
- NVIDIA CUDA Toolkit/runtime и cuDNN — компоненты NVIDIA с отдельными условиями NVIDIA; они не становятся MIT/Apache/BSD-компонентами из-за использования в проекте. Нужно учитывать лицензионные файлы/условия именно распространяемого runtime.
