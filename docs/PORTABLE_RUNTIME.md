# Portable runtime — baseline и inventory

> Снимок локальной рабочей установки владельца проекта от 2026-11-15. Это фактическая конфигурация одной Windows-машины, а не универсальные требования для всех систем и не гарантия чистого состояния GitHub-архива.

## Размещение

Код Stream TTS Studio загружается архивом GitHub и распаковывается непосредственно в корень установки. Portable runtime расположен рядом с кодом в каталоге `cosyvoice3\` и не отслеживается Git как часть исходников приложения.

В проверенной установке:
- корень Studio: `D:\TTS_release\`;
- portable runtime: `D:\TTS_release\cosyvoice3\`;
- portable Python: `cosyvoice3\upy\python.exe`;
- локальный FFmpeg: `cosyvoice3\tools\ffmpeg.exe`.

Владелец может вручную проводить тесты и менять файлы после распаковки архива. Поэтому этот снимок описывает реально используемую установку на дату проверки; он не привязан к Git commit и не утверждает, что все файлы совпадают с исходным архивом.

## Статус и границы снимка

- Python, PyTorch, CUDA/cuDNN, GPU, драйвер, FFmpeg, основные пакеты, каталоги и размеры зафиксированы по выводу локальной машины владельца.

- Версия FFmpeg подтверждена непосредственным запуском локального исполняемого файла.
- Снимок не включает Git commit, SHA-256 файлов, контрольную сумму архива или полный перечень всех файлов runtime.
- Размеры и версии относятся к состоянию на 2026-11-15 и должны обновляться при намеренном изменении portable runtime.
- Этот документ не является разрешением обновлять Python, CUDA, PyTorch, CosyVoice, модели или другие runtime-компоненты. Их изменение требует отдельного решения и проверки совместимости.


## Лицензии portable runtime — практический статус

Локальная проверка 2026-11-20 дополнила baseline фактическим снимком portable Python:

- Python: **3.10.11**, executable: `D:/TTS_release/cosyvoice3/upy/python.exe`.
- PyTorch: **2.7.1+cu128**; torchaudio **2.7.1+cu128**; torchvision **0.22.1+cu128**.
- CUDA build PyTorch: **12.8**.
- `torch.cuda.is_available()`: **True**.
- Полный вывод `pip freeze` получен от владельца; он подтверждает установленный набор Python-пакетов и версий. Полный перечень не дублируется в Git: для практического inventory достаточно этого снимка и перечня основных зависимостей выше.
- Ранее, в снимке 2026-11-15, была зафиксирована cuDNN **9.7.1 (90701)**. Команда от 2026-11-20 версию cuDNN отдельно не запрашивала, поэтому это остаётся предыдущим локальным наблюдением, а не повторно подтверждённым значением.

Значение `torch.version.cuda == 12.8` описывает CUDA-версию сборки PyTorch. Оно само по себе не означает, что в portable отдельно установлен полный CUDA Toolkit. `torch.cuda.is_available() == True` подтверждает доступность CUDA для данного окружения на проверенной машине, но не является инвентаризацией всех распространяемых NVIDIA DLL.

### Границы проверки

Практическая инвентаризация основных компонентов завершена в пределах информации, которую удалось собрать из исходного README, доступных upstream-материалов, локального снимка runtime и сведений о standalone FFmpeg Gyan. Полный список Python-пакетов намеренно не дублируется в Git; каждый транзитивный пакет и каждый бинарный файл отдельно не классифицировались.

Мы не проводили независимую полную проверку содержимого исходного portable-архива, всех вложенных DLL/PYD/EXE, файлов моделей и NVIDIA redistributables. Поэтому документация фиксирует известные сведения и не приписывает проекту проверку, которой не было. Неустановленные по доступным материалам детали относятся к исходной portable-сборке и её поставщику. Сохраняйте поставляемые вместе с runtime LICENSE/NOTICE; материалы по конкретной сборке Gyan FFmpeg и GPLv3 сохранены в `licenses/ffmpeg/`.
